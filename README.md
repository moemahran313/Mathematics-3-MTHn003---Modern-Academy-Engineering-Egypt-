# Mathematics 3 (MTH203 / MTHn103)
**Modern Academy for Engineering & Technology - Egypt**

Welcome to the comprehensive reference library and study hub for Mathematics 3. This repository is designed to provide engineering students with a structured, centralized, and interactive resource to master core applied mathematics concepts.

## 📖 Overview
This repository covers the complete syllabus for MTH203/MTHn103, bridging theoretical mathematics with practical engineering applications. It includes lecture notes, video courses, interactive quizzes, and a comprehensive archive of solved exams.

## 📚 Course Modules

### 1. Differential Equations
* **First-Order Differential Equations:** Separable, exact, linear, and Bernoulli equations.
* **Higher-Order Linear Equations:** Homogeneous and non-homogeneous equations with constant coefficients.
* **Engineering Applications:** Modeling physical systems and mechanical vibrations.

### 2. Laplace Transforms
* **Core Concepts:** Forward and inverse Laplace transforms.
* **Operational Theorems:** Shifting theorems, derivatives, and integrals of transforms.
* **Applications:** Solving linear differential equations and analyzing control systems.

### 3. Fourier Series
* **Fundamentals:** Periodic functions and trigonometric series.
* **Expansions:** Even and odd functions, half-range expansions.
* **Harmonic Analysis:** Applications in signal processing and heat conduction.

### 4. Legendre Polynomials
* **Power Series Solutions:** Solving differential equations around ordinary points.
* **Legendre's Equation:** Derivation and properties of Legendre polynomials.
* **Orthogonality:** Orthogonal properties and Fourier-Legendre series.
